# Lista Completa de Materiales (Hardware y Software)

Para garantizar el éxito del trayecto, cada grupo de estudiantes (recomendado 2 o 3 personas) debe contar con el siguiente equipamiento.

## 🛠️ Hardware Necesario (Por grupo)
- **1x Arduino Uno R3** (o compatible) + Cable USB.
- **1x Servomotor SG90** (9g) con sus respectivos brazos.
- **1x Protoboard** pequeña (170 o 400 puntos).
- **2x LEDs** (1 Verde y 1 Rojo/Amarillo).
- **2x Resistencias de 220 ohm** (para los LEDs).
- **Set de Cables Jumper** (Macho-Macho y Hembra-Macho).
- **1x Cámara Web** (Puede ser la integrada de la notebook o una USB externa).

### Materiales de Maquetación (Consumibles)
- Cartón, madera balsa o MDF.
- Pistola de silicona caliente o cinta de papel.
- Tijeras / Cúter.

---

## 💻 Software Necesario (Instalación por PC)

### Para el Camino Inicial (Opción PictoBlox)
- **[PictoBlox](https://pictoblox.ai/download-pictoblox/)**: Versión Desktop (Windows recomendada).
- **Extensión Machine Learning**: Se activa dentro del programa (requiere internet la primera vez).

### Para el Camino Avanzado (Opción Python)
- **[Arduino IDE](https://www.arduino.cc/en/software)**: Para programar la placa.
- **[Python 3.9+](https://www.python.org/downloads/)**: Instalado con "Add to PATH".
- **[Thonny IDE](https://thonny.org/)**: (Opcional) Un editor muy ligero y simple para principiantes.
- **Librerías de Python**: Se instalan con el comando:
  ```bash
  pip install opencv-python tensorflow pyserial numpy
  ```

---

## 🌐 Conectividad
- **Internet:** Es necesario durante los **Módulos 1, 2 y 4** para entrenar los modelos de IA en Google Teachable Machine o para descargar las extensiones de PictoBlox. El resto de las clases se pueden realizar de forma offline.
