# Guia del Camino Inicial: PictoBlox

Esta guia es para facilitadores que trabajen con alumnos que se inician desde cero absoluto.

## 1. Instalacion
1. Descargar e instalar **[PictoBlox](https://pictoblox.ai/download-pictoblox/)** (disponible para Windows, Mac y Linux).
2. Abrir el programa y seleccionar **Board: Arduino Uno**.

## 4. Logica de Programacion
El codigo se ve asi de simple:
- [Al hacer clic en Bandera Verde]
- [Abrir camara]
- [Por siempre]
    - [Analizar imagen de camara]
    - [SI clase detectada = "Plastico"]
        - [Mover Servo pin 9 a 90 grados]
    - [SINO]
        - [Mover Servo pin 9 a 0 grados]
