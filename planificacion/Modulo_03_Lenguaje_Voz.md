# Módulo 3: Lenguaje y Voz - El Robot que Escucha

## Objetivo
Explorar el Procesamiento de Lenguaje Natural (NLP) para permitir que el robot interactúe mediante comandos verbales y de voz.

## Cronograma (2.5 Horas)

### 1. El lenguaje de los humanos vs el de las máquinas (30 min)
- ¿Cómo traduce una máquina el sonido? (Frecuencia a Texto).
- NLU (Natural Language Understanding) vs NLG (Natural Language Generation).
- Ética: ¿Los robots "entienden" o solo "procesan"?

### 2. Reconocimiento de Voz (45 min)
- Uso de extensiones de "Speech Recognition" en PictoBlox o librerías de Python (como `SpeechRecognition`).
- Captura de palabras clave: "Adelante", "Atrás", "Detente".

### 3. Síntesis de Voz y Respuesta (45 min)
- Programar al robot para que responda verbalmente: "Entendido, moviéndome", "Objeto detectado".
- Personalización de la voz (Tono, velocidad, idioma).

### 4. Actividad Práctica: "El Mayordomo Robótico" (30 min)
- El robot debe realizar una rutina compleja al recibir una frase completa (ej: "Hola robot, traeme la merienda" -> el robot se mueve y responde).

---

## Materiales Requeridos
- Micrófono (integrado o externo).
- Parlante (o salida de audio de la PC).
- Kit de robótica móvil.
- Extensión de "Artificial Intelligence" y "Speech" en el software elegido.
